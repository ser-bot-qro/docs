# Documentación municipal de SER-QRO

Esta documentación explica la instalación del CLI, el primer despliegue y la operación de SER en los servidores municipales.

La guía se publica junto con la versión del CLI con la que fue distribuida. Usa el selector de versiones para consultar las instrucciones que corresponden a tu instalación; `latest` identifica la versión estable más reciente.

## Guía municipal

Consulta la [guía de instalación y operación](guia-municipal.md), que también se entrega como archivo Markdown en el paquete de distribución para uso sin conexión.

SER se distribuye como imágenes Docker privadas. El CLI administra esas imágenes y su despliegue; no instala Laravel desde cero.
